# 📱 QR Attendance System

A modern, fast, and secure cross-platform attendance tracking application built with **React Native**, **Expo**, and **Supabase**. Designed to streamline event check-ins and history monitoring for schools and organizations.

---

## ✨ Features

* **Instant QR Code Scanning:** Fast check-in processing via built-in camera scanning.
* **Secure Authentication:** User login and registration powered by Supabase Backend.
* **Attendance History:** Review past attendance logs and tracking metrics seamlessly.
* **Teacher/Event Dashboard:** Management tools for organizing and tracking events.
* **Modern UI/UX:** Polished styling with custom theme colors and responsive layouts supporting desktop and mobile views.

---

## 🛠️ Tech Stack

* **Framework:** [Expo](https://expo.dev/) (SDK 54 / React Native)
* **Routing:** [Expo Router](https://docs.expo.dev/router/introduction/)
* **Backend / Database:** [Supabase](https://supabase.com/)
* **Icons:** `@expo/vector-icons` (MaterialIcons)
